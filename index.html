  • Transaction Engine & Callback Handling: Membangun alur penukaran voucher, memvalidasi status kode voucher Pluxee, convert voucher merchant dan kirim hasil convert vouchernya ke email

E-Commerce Integration

Ringkasan Proyek

Mengembangkan arsitektur middleware dan backend services untuk mengintegrasikan Application Programming Interface (API) resmi marketplace terkemuka seperti Lazada (Open Platform API) dan Blibli (Merchant Open API) dengan sistem internal perusahaan. Solusi ini mengotomatisasi alur pemrosesan pesanan (order fulfillment pipeline) Bertanggung jawab atas perancangan integrasi sistem, otentikasi API berstandar keamanan tinggi (HMAC signature & OAuth 2.0 token management), pengelolaan automated cron job & task scheduler untuk pemrosesan transaksi berkala

Peran & Tanggung Jawab

Backend & Middleware Integration Developer

  • Marketplace API Integration (Lazada & Blibli): Mengimplementasikan integrasi protokol API resmi marketplace mencakup autentikasi token OAuth 2.0, signature HMAC security, endpoint order fetching & create Voucher
  • Automated Cron Job & Task Scheduler: Membangun skrip cron job di server Linux yang berjalan otomatis secara berkala untuk menarik (fetch), memvalidasi, dan memproses data transaksi serta sinkronisasi status pesanan secara konsisten dan terhindar dari duplikasi.
  • Error Handling, Audit Trail & Logging: Menyediakan sistem logging transaksi komprehensif untuk memantau traffic API, mencatat response code, serta mempercepat investigasi anomali transaksi atau pesanan gagal.
  • Production Deployment & Server Stability: Mengelola konfigurasi environment, deployment backend services ke server production Linux Ubuntu, serta pemeliharaan keandalan background process (systemd / supervisor).

Fitur Utama

  • End-to-End Automated Order Processing Pipeline
  • Official Marketplace Open API Integration (Lazada Open Platform & Blibli Merchant API)
  • Real-Time Webhook & Automated Cron Job Scheduler
  • Order Status Synchronization
  • Secure HMAC-SHA256 Signature & OAuth 2.0 Token Refresh Management
  • Transaction Audit Logging
